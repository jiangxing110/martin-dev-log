## 1. 前端要做什么

本次前端需要在客户相关页面增加“品牌名/DBA”和“官方网站”两个字段：

1. 页面增加查询输入框。
2. 列表增加品牌名/DBA、官方网站两列。
3. 新增/编辑客户时支持录入品牌名/DBA。
4. 品牌名允许多个，最多 10 个；单个品牌最多 128 个字符。
5. 品牌名去除首尾空格，并按不区分大小写去重。
6. 品牌名和官方网站同时填写时，按 AND 条件查询。

## 3. 字段定义

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `brandNameDba` | `string` 或 `string[]` | 否 | 品牌名/DBA。列表接口当前返回逗号分隔字符串；编辑详情建议使用数组 |
| `officialWebsite` | `string` | 否 | 官方网站 URL；列表展示字符串 |

注意：`brandNameDba` 在列表返回时可能是：

```text
Brand One, Brand Two
```

前端展示时可以直接展示；如果需要标签样式，可按 `, ` 拆分。详情编辑使用数组时，不要把官网混入品牌数组。

## 6. 新用户全量信息接口

页面：客户管理 → 客户信息 → 新用户全量信息。

接口：

```http
POST /api/admin/account/list
```

请求示例：

```json
{
  "pagination": {
    "current": 1,
    "size": 10
  },
  "brandNameDba": "品牌关键词",
  "officialWebsite": "example.com"
```

返回列表中的每条记录新增：


该接口支持两个字段的模糊查询，两个条件同时传入时按 AND 过滤。

后端对应实现：`AdminAccountUserController.accountList`、`AdminAccountDTO`、`AdminAccountVO`、`account.xml.selectAllAccount`。

## 7. Admin 人工维护品牌名/DBA

合规人员在客户详情/审核页面维护品牌名时，使用以下账户维度接口。人工维护只影响 `ADMIN` 来源，不会覆盖客户 API 报备产生的 `API_COMPLIANCE` 品牌。

### 7.1 查询账户品牌

```http
GET /api/admin/account/brand-name/list?accountId={accountId}
```

返回当前账户全部有效品牌记录，前端按 `brandName` 展示；`sourceType` 可用于展示来源：`API_COMPLIANCE` 为 API 报备，`ADMIN` 为合规人员人工维护。

### 7.2 新增/编辑品牌

```http
POST /api/admin/account/brand-name/save
Content-Type: application/json
```

```json
{
  "accountId": "账户ID",
  "brandNames": ["品牌1", "品牌2"]
}
```

该接口是“替换人工维护集合”：新增、编辑、批量删除统一提交最新数组；提交空数组表示清空全部人工维护品牌。API 报备品牌不会被删除。品牌最多 10 个，单个最多 128 个字符，服务端会 trim 并按不区分大小写去重。

### 7.3 删除单个人工品牌

```http
DELETE /api/admin/account/brand-name?accountId={accountId}&id={brandRecordId}
```

只能删除 `ADMIN` 来源记录；API 报备、KYC/KYB 自动同步记录不能通过该接口删除。

## 8. 输入校验和交互要求

- 品牌名为空字符串时不提交，或提交前过滤掉。
- 自动去除首尾空格。
- 同一账户内不允许重复品牌名，大小写不同也视为重复。
- 超过 10 个品牌时阻止提交，并提示：`品牌数量超限，保存失败`。
- 单个品牌超过 128 个字符时阻止提交，并提示：`品牌名长度不能超过128个字符`。
- 官网按普通字符串处理，建议前端校验 URL 格式，但不要擅自改写用户输入。
- 查询框点击清空后，应同时清除 `brandNameDba` 和 `officialWebsite`，重新请求列表。
- 查询条件回显时，不能把品牌名和公司法定名称混为一个字段。

## 9. 推荐组件交互

品牌名建议使用 Tag/Input 组件：

```text
[ Brand One × ] [ Brand Two × ] [请输入品牌名……]
```

回车或失焦生成一个品牌标签；提交前统一 trim、去重并校验数量和长度。

官方网站使用单行输入框：

```text
官方网站：https://example.com
```
