# 新加坡主体开户前后端对接

## 功能说明

该开关按账户单独配置，默认关闭。只有开关开启时，商户端 KYC 在注册国家选择“其他”后才允许将国家填写为 Singapore。国家名判断不区分大小写；其他国家的录入规则保持现有行为。

## GraphQL 字段

新增字段在 `AccountExtend` 上：

```graphql
allowSingaporeCompanyRegistration: Boolean!
```

账户查询通过 `Account.accountExtends` 返回。`accountModule` 是客户端 operation 名称；请在其现有账户信息 selection 中追加：

```graphql
accountExtends {
  allowSingaporeCompanyRegistration
}
```

如果页面只查询账户基础信息而没有选择 `accountExtends`，GraphQL 不会自动返回该字段。字段默认值为 `false`；客户端拿不到字段、字段为 `null` 或返回值不是 `true` 时，都按关闭处理。

## Admin：开启或关闭

调用现有管理员 mutation `openSpecialRole`。该 mutation 限管理员角色使用，需传目标账户 ID、开关状态和特殊权限枚举：

```graphql
mutation OpenSingaporeCompanyRegistration($data: OpenSpecialRoleInput!) {
  openSpecialRole(data: $data)
}
```

开启：

```json
{
  "data": {
    "accountId": "<目标账户ID>",
    "isOpen": true,
    "type": "singapore_company_registration",
    "remarks": "新加坡主体开户特批"
  }
}
```

关闭时将 `isOpen` 设为 `false`。成功返回 `true`。Admin 页面在 mutation 成功后刷新账户详情，再用 `accountExtends.allowSingaporeCompanyRegistration` 更新按钮状态：`false` 显示“启用”，`true` 显示“禁用”。

服务端会更新 `accountExtend.allowSingaporeCompanyRegistration`，记录包含账户、操作人、备注、配置名称及开通/关闭状态的权限备注日志，并记录通用特殊权限操作日志。该开关不是用户角色，不会执行角色新增或删除。

## Merchant：KYC 表单判断

商户端读取当前账户 `accountExtends.allowSingaporeCompanyRegistration`。注册国家选项为“其他”时，对“其他国家/地区”输入框执行以下判断：

```ts
const allowSingapore = accountExtends?.allowSingaporeCompanyRegistration === true;
const isSingapore = countryOther?.trim().toLowerCase() === 'singapore';

const singaporeAllowed = allowSingapore || !isSingapore;
```

行为约定：

| 注册国家 | 开关 | 输入值 | 行为 |
| --- | --- | --- | --- |
| 其他 | 关闭或缺失 | Singapore、singapore、SINGAPORE（含首尾空格） | 阻止提交，并提示该注册国家暂不支持 |
| 其他 | 开启 | 任意大小写的 Singapore | 允许继续提交 |
| 其他 | 任意状态 | 其他国家名 | 沿用现有校验 |
| 非其他 | 任意状态 | 不适用 | 沿用现有国家选择逻辑 |

大小写比较只用于判断开关规则。允许时，按现有 KYC “其他国家”字段的提交方式提交；不要因为该开关擅自把注册国家枚举从“其他”改成 Singapore，也不要改动其他国家的字段语义。

## 接口与字段速查

- 开关字段：`accountExtends.allowSingaporeCompanyRegistration`
- mutation：`openSpecialRole(data: OpenSpecialRoleInput!): Boolean!`
- 特殊权限类型：`singapore_company_registration`
- 开启：`isOpen: true`
- 关闭：`isOpen: false`
- 关闭默认值：`false`
- 商户端判断：只有字段严格等于 `true` 才允许 `Other + Singapore`
