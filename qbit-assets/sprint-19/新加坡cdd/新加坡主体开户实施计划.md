# 新加坡主体开户配置 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给指定账户增加新加坡公司主体开户开关，默认关闭，可通过 `openSpecialRole` 管理，并将状态和操作日志提供给前端。

**Architecture:** 在 `AccountExtend` 持久化 `allowSingaporeCompanyRegistration` 布尔字段，GraphQL 对象直接暴露该字段。扩展 `SpecialRoleTypeEnum` 和既有管理员 `openSpecialRole` 分支；该配置不调用角色增删，并写入权限备注日志及特殊权限操作日志。SQL 为已有账户新增默认关闭的非空列。

**Tech Stack:** NestJS, TypeORM, NestJS GraphQL, PostgreSQL SQL.

**Spec:** `docs/superpowers/specs/2026-10-26-singapore-company-registration-design.md`

## Global Constraints

- 字段名为 `allowSingaporeCompanyRegistration`。
- 数据库默认值为 `false`，列不允许 `NULL`。
- 使用 `openSpecialRole` 的 `accountId`、`isOpen`、`remarks` 配置账户。
- 这是账户级开户配置，不新增或删除用户角色。
- 管理员账户查询通过 `accountExtends` 返回该字段。
