# PD-2928 直客账单与 API 月账单、轧差账单分页筛选对接文档

## 1. 接口概览

| 页面/数据 | Method | URL | 返回列表项 |
| --- | --- | --- | --- |
| API 月结账单（含直客账单筛选） | POST | `/api/admin/quantum/card/openapi/customer/bill/list` | `QuantumCardApiCustomerBillVO` |
| 轧差账单 | POST | `/api/admin/quantum/card/openapi/customer/netting/invoice/list` | `ApiClientNettingInvoiceVO` |

请求体为 JSON。接口返回统一包装为 `Result<Page<T>>`，成功时 `code=200`、`message="success"`。分页对象主要字段为 `records`、`total`、`size`、`current`、`pages`。

## 2. 通用分页和客户类型

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `current` | number | 当前页，从 1 开始；默认 `1` |
| `size` | number | 每页条数；默认 `10` |
| `customerType` | string | 客户类型筛选：`API` 或 `DIRECT`；不传表示不按客户类型筛选 |

客户类型筛选规则：

- `API`：筛选 API 客户。月结账单也会包含历史 `customer_type` 为空的 API 账单。
- `DIRECT`：筛选直客。
- 轧差列表按账户类型区分；`API` 对应账户类型 `ApiClient`、`ApiClientCustomer`，`DIRECT` 对应非这两种类型的账户。
- 注意：筛选请求中的 `customerType` 始终传 `API` / `DIRECT`。响应字段的语义见各接口说明，轧差列表响应值不是上述筛选枚举。

## 3. API 月结账单列表

### 请求字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `current` | number | 当前页，默认 `1` |
| `size` | number | 每页条数，默认 `10` |
| `verifiedName` | string | 客户名称，按包含匹配 |
| `displayId` | string | 客户 ID；支持账户 UUID 或展示 ID |
| `billMonth` | string | 账单月份，格式示例：`2026-09` |
| `customerType` | string | `API` / `DIRECT` |
| `status` | string | 账单状态：`Settled`、`Pending`、`PartSettled`、`FREE` |
| `saleAdminId` | string | 客户经理 UUID |
| `startDate` | string | 账单创建时间起始值（含），按后端可解析的日期时间格式传入 |
| `endDate` | string | 账单创建时间结束值（含），按后端可解析的日期时间格式传入 |
| `systemType` | string | 系统类型：`QBIT`、`QbitInternational` |

只传需要的筛选项；未传或空字符串的可选字符串字段不参与筛选。分页字段可省略并使用默认值。

### 请求示例

```json
{
  "current": 1,
  "size": 20,
  "billMonth": "2026-09",
  "customerType": "API",
  "status": "Pending",
  "verifiedName": "客户名称"
}
```

### 列表项字段

返回 `data.records[]` 中的字段包括：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 月结账单 ID |
| `verifiedName` | string | 客户名称 |
| `displayId` | string | 客户展示 ID |
| `accountId` | string | 账户 ID |
| `customerType` | string/null | 账单客户类型：`API` / `DIRECT`；历史数据可能为空 |
| `status` | string | 账单状态 |
| `billMonth` | string | 账单月份 |
| `saleAdmin` | string | 销售经理 |
| `operatorAdmin` | string | 运营经理 |
| `remarks` | string | 客户备注 |
| `totalAmount` | number | 账单总额 |
| `debitAmount` | number | 还款金额 |
| `debitedAmount` | number | 记账金额 |
| `isLatest` | boolean | 是否为该月最新账单 |
| `checkStatus` | string | 复核状态，如 `Waiting`、`Done` |
| `debitType` | string | 还款方式，如 `Online`、`Offline` |
| `createTime` | string | 创建时间；当前 VO 使用毫秒时间戳的字符串形式 |
| `updateTime` | string | 更新时间；当前 VO 使用毫秒时间戳的字符串形式 |
| `systemType` | string | 系统类型：`QBIT` / `QbitInternational` |

## 4. 轧差账单列表

### 请求字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `current` | number | 当前页，默认 `1` |
| `size` | number | 每页条数，默认 `10` |
| `displayOrAccountId` | string | 商户展示 ID 或账户 UUID |
| `billMonth` | string | 月份，格式示例：`2026-09` |
| `customerType` | string | 类型筛选：`API` / `DIRECT` |
| `verifiedName` | string | 账户名称，按包含匹配 |
| `status` | string | 轧差账单状态：`Settled`、`Pending`、`PartSettled` |
| `saleAdminId` | string | 客户经理 UUID |
| `operationManagerId` | string | 运营经理 UUID |

只传需要的筛选项；未传或空字符串的可选字符串字段不参与筛选。

### 请求示例

```json
{
  "current": 1,
  "size": 20,
  "billMonth": "2026-09",
  "customerType": "DIRECT",
  "status": "Pending",
  "displayOrAccountId": "C10001"
}
```

### 列表项字段

返回 `data.records[]` 中的字段包括：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 轧差账单 ID |
| `billId` | number/null | 关联账单 ID |
| `accountId` | string | 账户 ID |
| `displayId` | string | 商户展示 ID |
| `verifiedName` | string | 商户名称 |
| `customerType` | string/null | **账户原始类型**，例如 `ApiClient`、`ApiClientCustomer`、`Merchant`；不要按 `API` / `DIRECT` 枚举解析或直接展示该值 |
| `billMonth` | string | 月份 |
| `rebateAmount` | number | 应返现金额 |
| `billAmount` | number | 应月结金额 |
| `amount` | number | Net 应付/应收金额 |
| `dealAmount` | number | 已支付金额 |
| `remainAmount` | number | 未支付金额 |
| `dateDuration` | string/null | 日期范围 |
| `status` | string | `Settled`、`Pending`、`PartSettled` |
| `type` | string/null | 轧差账单类型：`NettingRebate`、`NettingDebit`、`NettingEqual` |
| `oldType` | string/null | 更新前的账单类型 |
| `showUpdateRebate` | boolean/null | 是否展示更新返现 |
| `saleAdminName` | string/null | 客户经理 |
| `operationManagerName` | string/null | 运营经理 |
| `createTime` | string | 创建时间；当前 VO 使用毫秒时间戳的字符串形式 |
| `updateTime` | string | 更新时间；当前 VO 使用毫秒时间戳的字符串形式 |

其中 `customerType` 返回数据库关联账户的 `account.type` 原值（`AccountTypeEnum`），接口不会把它转换成 `API` / `DIRECT`。若前端需要展示客户大类，应基于账户类型映射：`ApiClient`、`ApiClientCustomer` 映射 API，其余账户类型映射直客；筛选仍传 `API` / `DIRECT`。

## 5. 前端接入建议

- 分页组件的页码和每页条数映射到 `current`、`size`；翻页或改变筛选条件时重新请求。
- 客户类型筛选控件传 `API` / `DIRECT`；清空筛选时省略 `customerType` 或传 `null`。
- 月结账单列表可以直接读取 `customerType` 的 `API` / `DIRECT` 值；轧差账单列表的同名字段是账户类型原值，不要复用月结账单的枚举展示逻辑。
- 状态字段按接口枚举值传递，不要传中文文案。
- 金额按 JSON number 接收；时间字段按毫秒时间戳字符串处理。
