# BB / QI 客户成本项明细查询方案

## 摘要

新增 BB、QI 两条客户成本明细查询，保留现有汇总查询及 account_id、日期范围、API 子户并入主户逻辑。每项展示计费基数、rate（适用时）和金额，并追加总成本行。渠道返现收入另以“收入”类型列出，不计入成本总计。

## 方案

- 采用单一结果集，每项成本一行，便于 SQL 客户端筛选、导出和汇总。
- 另用一行列出总成本，方便与原总额查询核对。
- QI rate 用汇总金额 / 汇总基数作为加权展示；固定费用不展示费率。
- 不改原汇总查询、DWS 成本公式和 API 主子户归属范围。

## 输出字段

渠道、客户输入 ID、归集主户 ID、期间、DWS 账户数、DWS 行数、项目类型、成本项、基数、展示费率、金额。
