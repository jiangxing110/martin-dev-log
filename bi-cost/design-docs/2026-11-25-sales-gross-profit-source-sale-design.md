# 销售毛利视图按源表销售归属

## 摘要

销售归属以每个来源的 `sale_id` 为准。提前排除空白销售归属，移除销售关系维表查询，并合并 BB、QI、BZ 的每日成本与渠道返现计算，减少生成物化视图需要的扫描和聚合。

## 处理规则

- 源表 `sale_id` 原值用于分组、结果输出和成本匹配。空值、空字符串及全空格数据不进入视图。
- API 子账户仍归到根账户用于客户维度，根账户映射不参与销售归属。
- 原先依靠回查归属的 ODS 支付手续费、离线退款和月度调账退出视图。月度汇总表中已有 `sale_id` 的 API 应收和离线 API 收入继续纳入。
- BB、QI、BZ 在同一个日汇总中计算原有成本和返现公式。成本和返现继续写出各自的来源维度。

## 验收

核对时间窗口、输出字段、金额公式和来源维度。在线耗时以重建和刷新实际执行结果为准。
