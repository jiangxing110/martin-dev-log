## BB 7月成本一夜 +26,404 归因分析（CDC 双写者问题）

背景：v4 查询昨晚 7 月成本 432,056.00（≈实际），今天 458,459.73（+26,404）；8 月也 +62k。5 月也曾跳 +43.4k（458,826 → 502,226）。

链路机制（flink/quantum-v2/bb）：
- DWM CDC（dwm_online_bb_card_transaction_detail_v2-cdc-sql.sql）：按**昨日事件时间窗口**（transaction_time / original_completion_time / settlement postDate）同步源库，不按 update_time 追变更。DWM 行 update_time = 源交易 update_time（COALESCE(t.update_time, t.create_time, CURRENT_TIMESTAMP)）。
- DWS CDC（dws_online_bb_card_finance_daily_v2-cdc-v2-sql.sql）：扫 DWM 近 24h update_time/delete_time 变更 → 命中 (月份+账户) 后**整月重算**，upsert（PK id=hash(月:账户:sale:am)），**不删除**（fn_delete_bb_card_finance_daily_v2_cdc 只计数不删除）。
- 月度 Batch（monthly-cdc）：fn_delete 删上月 DWS + 整月重插（writeMode='insert'），备注 bb_v2_batch_q3_refund_net_20260721。

核心风险（双写者口径漂移，最可能主因）：
- daily CDC（口径A）与 monthly Batch（口径B）指标定义不一致：Batch 有 16 个黑名单 settlement 排除（is_excluded_settlement）、auth 计数排除 business_code_list 1010、refund 按 transaction_type='refund.clearing'；CDC 无排除过滤、refund 要求 is_valid_settle、rebate base 要求 settlement_match_type='card_transaction_id'。同一 DWS 表 last-writer-wins，closed 月份被 CDC 覆盖后数值漂移。
- 结构性风险：CDC 只 upsert 不删除，若 sale/am 归属变更 → 新 id 新行 + 旧行残留 → 同月同账户双计。
- update_time 语义：DWM 行 update_time=源交易 update_time，变更扫描不可靠（漏扫/误扫）。
- 8/10 有 delete_bb_qi_dwm_dws_2026_07_08.sql（删 7/8 月 DWM+DWS）→ 重灌与 CDC 并发可能交错。
