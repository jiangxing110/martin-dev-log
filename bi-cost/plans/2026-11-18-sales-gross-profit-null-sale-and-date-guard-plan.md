# 销售毛利空销售过滤与最早日期限制执行计划

## 目标

统一阻止空销售数据进入毛利视图和新快照，并阻止 API 查询 2026-09-01 之前的数据。

## 步骤与进度

- [x] 在毛利估算物化视图最终查询过滤 `NULL`、空字符串和全空格 `sale_id`。
- [x] 在快照批处理来源查询过滤空销售，并在汇总、明细快照 DDL 中设置 `NOT NULL` 和非空白约束。
- [x] 在生产与本地 Mapper 的快照存在性判断、查询，以及生产估算查询中排除空销售。
- [x] 回填销售名称前跳过空白 ID，避免空字符串触发 UUID 类型转换错误。
- [x] 在共享服务查询校验中限制 `settlementMonth` 和 `reportDateRange` 起始日不得早于 2026-09-01。
- [x] 将参数/权限校验异常改用全局异常处理器识别的 `CustomException`，确保返回 400/403 和对应提示信息。
- [x] 物化视图与独立指标 SQL 将 Open API 实收改为实际实收指标减去月结 KYC、实体卡手续费和最低承诺三项实收。
- [x] 对涉及的 SQL/Java 仓库执行 `git diff --check`；遵守用户要求，不编译、不运行测试、不执行数据库语句。

## 交付说明

DDL 文件用于后续建表或重建。既有数据库快照中的空销售记录不会因修改脚本而自动删除；API 查询和快照存在性判断已过滤这些记录。若需物理清理历史记录，应另行确认清理范围并执行数据维护。
