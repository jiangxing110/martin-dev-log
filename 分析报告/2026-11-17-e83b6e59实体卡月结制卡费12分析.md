## 月结判断读取什么数据

对于超过 4 小时的历史时间，`getCaasMonthFee` 从 API 根账户的 `OperationLog` 重建 `statementType` 时间段，再用交易时间判断 Monthly/Realtime，见 [account-fee.service.ts:2105-2152](/Users/martinjiang/WebstormProjects/qbitpay_service/src/modules/account-fee/account-fee.service.ts:2105) 和 [account-fee.service.ts:2184-2244](/Users/martinjiang/WebstormProjects/qbitpay_service/src/modules/account-fee/account-fee.service.ts:2184)。区间判断为左闭右开。

因此，提供的月结区间覆盖两笔交易，不等于此函数必然命中；需要确认根 API 账户的 `OperationLog` 中确实存在对应 `Monthly` 记录。若操作日志区间未覆盖，函数会判为 Realtime，旧表路径就会查询普通 `ByApi`。

此外，如果 `account_fee_item` 查询先命中，旧表的 CaaS 转换不会运行。这是当前最值得优先排查的代码分支。
